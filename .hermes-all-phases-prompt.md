## What This Project Is

ArkaLedger is an automated multi-site P&L consolidation and financial reporting platform for PT. Arkananta (Indonesia mining contractor). It replaces a manual monthly process where CPAs compile a 21-sheet Excel workbook from SAP B1 exports + emailed reports across 9 project sites.

## Tech Stack (Non-Negotiable)
- Laravel 13 + PHP 8.5
- Inertia.js + React + Ant Design Pro (ProTable, ProLayout)
- MySQL schema `inhouse_pnl`
- Laravel Horizon (Redis queue)
- PhpSpreadsheet + openspout for Excel (DO NOT use maatwebsite/excel — blocked on PHP 8.5)
- DomPDF for PDF
- Ant Design Charts / Recharts
- Spatie Permission (per-site scoping)
- npm always with `--legacy-peer-deps`

### Phase 1: Data Ingestion & P&L Dashboard MVP (Steps 1.1–1.9)

1.1 — Import/staging schema: import_batches (mirrors SapSyncRun pattern: status, created/updated/failed counts, error_summary, triggered_by, source), sap_staging (raw rows from uploaded files with provenance to import_batch_id).

1.2 — Intelligent Excel parser service class (`app/Services/SapExcelParser.php`): reads SAP export file, detects the "SAP" marker row, identifies column layout (two-column: left=2024 baseline, right=current year), maps columns to accounts, returns structured staging rows. Handle both Rincian (detail) and P&L (summary) sheet formats.

1.3 — Import batch processing: Job class (`app/Jobs/ProcessImportBatch.php`) queued via Horizon. Stages rows → maps CoA → validates → upserts into account_balances. Track status on import_batches.

1.4 — account_balances schema: (report_period_id, project_site_id, account_id, debit, credit, balance, source enum, import_batch_id, is_locked). Unique constraint on (report_period_id, project_site_id, account_id, source). Indexes on all FKs.

1.5 — P&L Aggregation Service (`app/Services/PnlAggregator.php`): rolls up account_balances into pnl_snapshots/pnl_snapshot_lines per the pnl_lines hierarchy. Uses sign (+1/-1) for math. Computes TOTAL at query time (not stored). Stores only monthly amounts; AVG and % derived at query time per plan.md decision.

1.6 — Import Center UI: ProTable of import_batches with status chips (pending/processing/completed/failed), upload wizard (Ant Design Steps: Upload file → Auto-detect layout → Preview mapping → Confirm import). Live progress via polling or Horizon job status.

1.7 — Site P&L Page: ProTable with frozen left column for account hierarchy labels, two macro-column groups (2024 baseline | current year) each with Jan–Dec + TOTAL/AVG/%, expandable rows for hierarchy (Revenue → Cost of Sales → Fuel → Fuel Transport), view toggle Rincian↔P&L, right-side variance panel, site selector dropdown.

1.8 — Consolidated P&L Page: All-sites combined ProTable, per-site contribution stacked bar chart, period selector.

1.9 — Dashboard Home: 4 KPI cards (Revenue, Cost IPH, Net P&L, vs 2024 % with green/red trend arrows), 24-month revenue/cost trend line chart, per-site contribution stacked bar, insights feed (anomaly alerts placeholder), site status board per plan.md wireframe.
